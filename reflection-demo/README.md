# Daily Reflection 成长卡牌 Demo

从仓库根目录运行 `python3 -m http.server 4193 --directory reflection-demo`，访问 `http://127.0.0.1:4193/`。

页面使用设备本地日期。完成反思后，本地匹配器会从光、风、影、火、水、森、梦、时八个系列中推荐一条成长线；用户确认后解锁 Lv.1，相似经历中的更深理解会继续推动卡牌升级。卡册包含 64 条成长线和 192 张等级卡面。页面宽 390px、高 844px；窄屏手机自动铺满。微信登录、真实 AI 匹配及通知发送尚未接入，记录和卡牌仅保存在当前浏览器。
