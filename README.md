# 每日一思（Daily Reflection）

每日一题 + 反思写作 + 打卡激励的思考类小程序。当前为**产品验证阶段的高保真 Demo**（单文件 HTML，浏览器直接打开即可运行），正式版将按原生微信小程序 + 云开发实现。

## 仓库结构

```
├── README.md                 # 本文件
├── AGENTS.md                 # AI 编码助手协作规范（改代码前必读）
├── demo/
│   └── index.html            # 高保真 Demo v0.6（单文件，无依赖，无构建）
└── 每日一思-产品方案.md        # 产品方案：定位 / MVP 切分 / 数据模型 / 路线图
```

## 快速运行

```bash
# 方式一：直接双击 demo/index.html
# 方式二：本地服务器
cd demo && python3 -m http.server 8765
# 打开 http://localhost:8765
```

## Demo 功能一览（v0.6）

- **今日（Tab1）**：每日一题（30 题库按日期轮换）+ 写作区自动保存 + KPT / 月复盘入口 + 连续天数（含最近 7 天迷你打卡条）+ 本月打卡圆环
- **回顾（Tab2）**：打卡日历（可翻月、可点日期进详情）+ 连续天数 + 月度打卡率 + 下一枚印记 + 书签集邮册横滑
- **我的（Tab3）**：头像 hero + 回顾记录入口 + 书签集邮册入口 + 提醒 / 推送 / 反馈设置
- **金句书签集邮系统**：从用户当日反思中提取金句，生成竖排衬线书签卡（含朱红"思"印章），集邮册全页浏览 + 大图预览
- **日期详情页**：4 种状态（今日可写 / 已打卡 / 未打卡 / 未来）

## 设计与技术约定

- **视觉**：Bento Grid 风格 —— CSS Grid 不规则卡片（col-span-2 / row-span-2）、统一 gap、rounded-2xl 圆角、zinc 中性色 + 琥珀/玫红/紫/青 4 组渐变强调卡、hover 上浮 + 微缩放 + 阴影扩散
- **字体**：Noto Serif SC（衬线标题）+ 系统无衬线（正文）
- **正则技术栈（正式版）**：原生微信小程序 + CloudBase 云开发（云数据库 + 云函数）+ 订阅消息
- **数据模型**：`users` / `questions` / `entries` / `reviews` 四集合，详见产品方案文档
